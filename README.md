# Taste of Haven

A complete responsive restaurant website built with **React + Vite** only on the application side.

## Features

- Responsive restaurant landing page
- Menu categories and filtering
- Add/remove/update cart
- Client-side order flow
- Table reservation form
- About/story section
- Contact/footer section
- Mobile responsive layout
- No backend required for this demo

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production files are generated inside `dist/`.

## Deploy

This project can be deployed to Vercel, Netlify, AWS S3/CloudFront, or any static hosting service.

### Important

This is a frontend-only website. Orders and reservations are simulated in the browser and are not persisted to a database or sent to a restaurant. For a real production ordering/reservation system, connect the forms to a backend/API and payment provider.
